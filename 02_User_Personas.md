# ExaminerHub User Personas

## Purpose

This document defines every type of user who will use ExaminerHub.

Each user has different goals, permissions and responsibilities.

Design decisions throughout the application must consider the needs of each persona.

---

# Persona 1 – Examiner

## Description

A Cambridge English examiner who delivers speaking examinations, invigilates written examinations and may also act as a supervisor.

## Primary Goals

* View upcoming sessions
* Accept or decline session offers
* Read session briefings
* View partner examiner
* View supervisor
* Access Zoom links for remote sessions
* Record session details
* Generate invoices
* Track earnings
* View monitoring status
* View certification status

## Biggest Frustrations

* Searching emails for information
* Forgetting session details
* Manual invoice preparation
* Missing important updates
* Not knowing when monitoring is due

## Success Measures

The examiner should be able to complete almost every administrative task from ExaminerHub without searching emails.

---

# Persona 2 – Supervisor

## Description

An examiner responsible for supervising a session.

## Responsibilities

* Collect confidential materials
* Prepare examination rooms
* Brief the examiner team
* Return confidential materials
* Complete supervisor duties
* Report incidents

---

# Persona 3 – Team Leader

## Description

Responsible for monitoring examiner quality and supporting examiners.

## Responsibilities

* Monitor examiners
* Record monitoring outcomes
* Provide feedback
* Schedule monitoring sessions
* Review examiner performance

---

# Persona 4 – Centre Manager

## Description

Responsible for organising examination sessions.

## Responsibilities

* Schedule sessions
* Assign examiners
* Publish briefings
* Manage candidate adjustments
* Communicate important information
* View staffing reports

---

# Persona 5 – Kensite Administrator

## Description

System administrator responsible for the operational management of ExaminerHub.

## Responsibilities

* Manage organisations
* Manage fee rates
* Manage centres
* Approve invoices
* Process payments
* Generate reports
* Configure the system
