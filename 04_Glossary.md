| Term                 | Meaning                                                           |
| -------------------- | ----------------------------------------------------------------- |
| Session              | A scheduled examination activity involving one or more examiners. |
| Speaking Examiner    | Examiner responsible for conducting the speaking test.            |
| Invigilator          | Examiner responsible for supervising written examinations.        |
| Supervisor           | Examiner responsible for the overall running of a session.        |
| Team Leader          | Person responsible for monitoring and supporting examiners.       |
| Briefing             | Information supplied by the examination centre before a session.  |
| Monitoring           | Observation and assessment of an examiner's performance.          |
| Annual Certification | Mandatory yearly standardisation meeting.                         |
| Partner Examiner     | Examiner working alongside another speaking examiner.             |
