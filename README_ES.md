# Documentación de ExaminerHub

Bienvenido/a a la **documentación de ExaminerHub**.

Este repositorio contiene toda la documentación relacionada con el
diseño, la arquitectura, el desarrollo y la evolución de
**ExaminerHub**.

ExaminerHub es una plataforma full-stack diseñada para simplificar y
digitalizar la gestión de las operaciones relacionadas con los exámenes
orales.
